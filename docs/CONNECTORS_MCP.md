# Интеграции TaalimSpace

| Интеграция | Назначение | Настройки |
| --- | --- | --- |
| PostgreSQL / Supabase | Аккаунты, уроки, чаты, ДЗ | DATABASE_URL |
| Groq | Тьютор, Whisper, анализ, план учителя | GROQ_API_KEY, GROQ_TEXT_MODEL, GROQ_AUDIO_MODEL |
| Zoom | Внешний урок по ссылке в чате | API и ключи не нужны |
| Stripe | Будущая тестовая оплата | Пока не подключён |
| Vercel / Render | Планируемый хостинг | См. DEPLOYMENT.md |

Supabase используется как сервер PostgreSQL через SQLAlchemy/psycopg.
Ключи SUPABASE_SECRET_KEY, publishable и JWKS для текущей авторизации не нужны:
пароли хешируются backend, JWT подписывается AUTH_SECRET.
Запись Zoom загружает пользователь вручную; сайт не скачивает произвольные URL.

MCP-сервер не реализован и не требуется для данного сценария.
Будущие MCP-инструменты должны повторять серверные проверки доступа;
наличие MCP не заменяет API, авторизацию и хранение данных.
