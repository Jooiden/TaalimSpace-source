# TaalimSpace — полный чек-лист

Дата сверки: 8 октября 2026. Основание: первоначальное ТЗ, последующие решения пользователя, текущий код и результаты проверок. «Реализовано» означает наличие работающей логики в коде; это не подтверждает прохождение всего сценария на размещённом сайте.

## 1. Аккаунты
- [x] Единая регистрация: имя, email, пароль; без выбора роли.
- [x] Вход, выход, серверная проверка пользователя.
- [x] Все пользователи могут учиться.
- [x] Подключение преподавания через публикацию профиля.
- [x] Переключение «Учусь / Преподаю», раздельные уроки и ДЗ.
- [x] Учитель может бронировать чужие занятия, сдавать задания и оставлять отзывы.
- [x] Запрет брони своего урока и проверки своего ДЗ.
- [x] Сохранение входа после обновления через HttpOnly-cookie; серверные тесты пройдены.
- [x] Одноразовое восстановление пароля через Brevo/SMTP; требует настройки отправителя и проверки доставки.
- [ ] Подтверждение email при регистрации.
- [x] Настройки профиля: необязательная приватная дата рождения и часовой пояс.
- [x] Отдельные разделы занятий и домашних заданий с работающей навигацией.
- [ ] Остальные настройки аккаунта: смена имени, языка и пароля из личного кабинета.

## 2. Преподаватели и каталог
- [x] Каталог и профиль преподавателя, фильтры и сортировка.
- [x] Демо-преподаватели явно обозначены и оставлены по решению пользователя.
- [x] Реальные услуги доступны в /catalog и /offers, демо отдельно в /catalog?demo=1.
- [x] Создание и редактирование своей услуги: предмет, описание, языки, опыт, цена.
- [x] Средняя оценка, число отзывов и завершённых занятий.
- [x] Единый путь поиска и бронирования реальных преподавателей.
- [x] Тексты отзывов в профиле.
- [x] Загрузка фотографии преподавателя.
- [x] Несколько независимых услуг одного преподавателя с разными ценами.
- [x] Скрытие и снятие дополнительной услуги с публикации.
- [ ] Реальная модерация и подтверждение преподавателя; метка в интерфейсе сама по себе не является проверкой.

4. Настройки аккаунта, редактирование AI-материалов, вложения к ответу ДЗ и подробная аналитика.
5. Реальная модерация преподавателей и эксплуатационные ограничения/мониторинг.

Внешние зависимости не скрываются: пользователь создал аккаунт Brevo и настраивает
ключ/отправителя. Письма, push, Stripe и размещение не считать проверенными по наличию кода.
