# Подключение писем TaalimSpace

## Блокировка IP в Brevo

Settings → Security → Authorized IPs: разрешить доверенный исходящий адрес сервера.
IP учеников не нужны: запросы к Brevo отправляет backend TaalimSpace. После размещения
нужно разрешить исходящие адреса нового сервера. Отключать защиту для всех IP
для работы сброса пароля у всех пользователей не требуется.

9 октября 2026: блокировка текущего адреса снята владельцем; account/senders
вернули 200 и подтвердили отправителя. Доставку письма проверять отдельно.

1. Зарегистрируйтесь на https://www.brevo.com/ . На момент проверки Free включает 300 писем в день: https://help.brevo.com/hc/en-us/articles/208580669-FAQs-What-are-the-limits-of-the-Free-plan . Доступ к отправке может потребовать активации аккаунта.
2. Settings → Senders, Domains, IPs → Senders → Add a sender. Добавьте и подтвердите адрес отправителя. Для своего домена выполните предложенную Brevo настройку DNS. Не обещаем доставку без проверки отправителя. Официальная инструкция: https://help.brevo.com/hc/en-us/articles/208836149-Create-a-new-sender-From-name-and-From-email
3. Создайте API key в SMTP & API → API Keys. Сохраните локально в серверном .env как BREVO_API_KEY. Не отправляйте ключ в чат.
4. В SMTP_FROM укажите подтверждённую почту отправителя. Имя параметра общее для обоих транспортов; SMTP_HOST при использовании Brevo API не нужен.
5. FRONTEND_URL должен быть адресом вашего сайта. Сейчас http://127.0.0.1:5173; после публикации — HTTPS адрес Vercel/домена.
6. Перезапустите сервер. Проверьте «Забыли пароль?» на собственной зарегистрированной почте, затем повторное использование ссылки (должно быть запрещено).
7. В разделе «Уведомления» включите отправку напоминаний по почте.

Есть также SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD для другого SMTP-провайдера. Используется TLS. На хостинге удобнее HTTPS API.

Восстановление пароля работает с одноразовыми ссылками на 30 минут. Смена пароля завершает все сохранённые сессии. Система не сообщает постороннему, зарегистрирован ли указанный email.

Документация: https://developers.brevo.com/docs/send-a-transactional-email
